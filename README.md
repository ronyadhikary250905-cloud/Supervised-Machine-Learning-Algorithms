# Supervised Machine Learning

This repository contains my hands-on implementations of various Supervised Machine Learning algorithms using Python.

## Algorithms Covered

- Linear Regression
- Lasso and Ridge Regularization
- Logistic Regression
- Naive Bayes
- K-Nearest Neighbors (KNN)
- Decision Trees
- Support Vector Machines (SVM)
- Random Forest
- Gradient Boosting
- AdaBoost
- XGBoost
- Bagging
- Boosting
- Voting
- Stacking

## Technologies & Libraries

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Learning Objectives

- Understand Supervised Machine Learning algorithms.
- Implement Regression and Classification models.
- Explore Ensemble Learning techniques.
- Evaluate model performance using different metrics.
- Gain practical experience through hands-on implementation.
